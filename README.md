## 📖 Overview

**Code Orbit Security Toolkit** is a professional, AI-powered cybersecurity suite developed as part of the **Code Orbit Tech Internship** program. It combines **4 essential security tools** into one interactive dashboard, making cybersecurity accessible and understandable for everyone.

> 🎯 **What makes this toolkit special?**  
> Every tool is designed with **AI-like intelligence**, providing actionable insights, real-time feedback, and professional-grade analysis — all wrapped in a beautiful, user-friendly interface with a **dark theme**.

## ✨ Features

### 🔐 1. Password Strength Checker
> *Know your password's true strength*

- ✅ AI-powered scoring (0-100 scale)
- ✅ Entropy calculation (bits of randomness)
- ✅ Breach detection (HaveIBeenPwned API integration)
- ✅ Crack time estimation (from milliseconds to centuries)
- ✅ Detailed feedback with improvement suggestions
- ✅ Password generator (cryptographically secure)

### 🔑 2. Caesar Cipher Toolkit
> *Learn encryption the classic way*

- ✅ Encrypt any text with custom shift
- ✅ Decrypt Caesar cipher encrypted text
- ✅ Brute Force cracking (tries all 25 shifts)
- ✅ Confidence scoring for each possible decryption
- ✅ Educational analysis with historical context

### 🎣 3. Phishing Email Detector
> *Don't take the bait*

- ✅ AI-powered email analysis
- ✅ URL reputation and domain checking
- ✅ Red flag detection (urgency, spoofing, attachments)
- ✅ Risk scoring (0-100 scale)
- ✅ Actionable recommendations
- ✅ Sample emails for training

### 🌐 4. Network Port Scanner
> *See what's open on your network*

- ✅ Multi-threaded scanning (fast!)
- ✅ CVE vulnerability mapping (known exploits)
- ✅ Service detection with banner grabbing
- ✅ Risk scoring and security recommendations
- ✅ Educational information about each port
